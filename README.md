# Estamparia: versões

Este repositório guarda só os instaladores do **Estamparia** (montagem de folhas DTF e editor de estampas para Windows). O código-fonte é privado.

- Baixe a versão mais nova em **[Releases](https://github.com/rodrigoaude1/estamparia-releases/releases/latest)**: o `-instalador.exe` instala e se atualiza sozinho (o app pergunta antes de baixar); o `-portatil.exe` roda sem instalar.
- O app instalado procura atualizações aqui.
